# 아이디어 탐색 페이지 — 선택지 다양화 리서치

작성일: 2026-08-18 · 대상: StoryHelperLite "아이디어 탐색" 탭의 `STORY_GUIDE_SLOTS` 6개 카테고리 확장

---

## 1. 현재 상태 (data.js `STORY_GUIDE_SLOTS`)

드롭다운(select) 6개 카테고리, 옵션 선택 시 조언(tip) 문구가 뜨고 전체를 조합해 줄거리 미리보기 문장을 만드는 구조입니다. 각 드롭다운에는 "직접 입력…" 옵션이 이미 있어 목록에 없는 값도 자유 입력할 수 있습니다.

| 카테고리 | 현재 옵션 수 | 옵션 |
|---|---|---|
| 주인공의 성격 | 6 | 소심·내향적 / 당당·외향적 / 냉철·이성적 / 유쾌·낙천적 / 반항·충동적 / 야망·계산적 |
| 목적 | 6 | 생존 / 사랑·관계 회복 / 복수 / 진실 규명 / 인정받기·자아실현 / 정의 실현·구원 |
| 변화 | 4 | 성장형 / 타락형 / 발견형 / 불변형 |
| 세계관 | 6 | 현실 세계 / 시대극·사극 / 이세계·판타지 / SF·미래 / 초자연·호러 / 디스토피아 |
| 플롯의 종류 | 6 | 성장·입문 서사 / 복수극 / 추적·탐정물 / 로맨스 / 구출·모험 서사 / 반전·서스펜스 |
| 엔딩의 종류 | 6 | 해피 / 새드 / 열린 결말 / 배드(파국) / 비터스윗 / 반전 |

카테고리당 4~6개뿐이라 선택 폭이 좁고, 특히 "변화"는 4개뿐입니다. 아래는 각 카테고리를 검증된 작법 프레임워크와 최신 웹툰 트렌드로 넓히기 위한 리서치입니다.

---

## 2. "변화" (캐릭터 아크) — 3대 아크 이론으로 재정비

작법론에서 캐릭터 아크는 크게 3가지로 분류됩니다 (K.M. 웨일랜드의 아크 이론 기반).

- **긍정형(Positive Arc)** — 거짓 믿음을 버리고 진실을 받아들이며 성장. (현재의 "성장형"과 동일)
- **부정형(Negative Arc)** — 거짓 믿음에 굴복하거나 더 깊이 빠져듦. (현재의 "타락형"과 동일하지만, 아래처럼 세분화 가능)
  - *환멸형* — 순진한 믿음이 깨지며 냉소적으로 변함
  - *몰락형* — 완전한 파국으로 치닫음 (기존 "타락형"에 가까움)
- **평탄형(Flat Arc)** — 인물은 변하지 않고, 그 신념이 주변 세계·인물을 변화시킴 (기존 "불변형"과 유사하지만 "세계를 바꾸는 주체"라는 점이 더 명확함)

기존 "발견형(자각·각성)"은 위 3대 분류에 없는 독자적 유형으로 그대로 유지할 만합니다. 정리하면 **4→6~7개**로 늘릴 수 있습니다: 성장형 / 환멸형 / 몰락형 / 발견형 / 불변형(평탄형) / 시험형(신념을 지키려는 시련을 반복적으로 통과하며 단련되는 유형) 등.

---

## 3. "목적" — 캐릭터 동기 카테고리로 확장

브린 도노반의 캐릭터 목표 정리에 따르면 동기는 다음 큰 범주로 나뉩니다. 현재 6개 중 상당수가 이미 이 범주와 겹치지만, 빠진 범주를 채우면 선택폭이 넓어집니다.

- 개인적 성장·자아실현 (기존)
- 사랑·관계 (기존)
- **생존·안정** (기존 "생존"과 겹치되, "안정적 삶 확보"처럼 톤을 달리한 하위 옵션 추가 가능)
- 정의·복수 (기존)
- **모험·탐험** — 새로운 세계·경험에 대한 갈망 (신규)
- **권력·영향력** — 위치·질서를 바꾸고 싶은 욕구 (신규)
- **자유** — 속박·굴레에서 벗어나기 (신규)
- **소속감** — 공동체·가족의 일원이 되기 (신규)
- **보호** — 소중한 사람·가치를 지키기 (신규)

→ 6개에서 **10~11개**로 확장 가능.

---

## 4. "세계관" — 웹툰 트렌드 장르로 확장

기존 6개는 고전적인 장르 분류(사극/판타지/SF/호러/디스토피아)에 가깝습니다. 여기에 최근 웹툰·웹소설 시장에서 강세인 설정을 추가하면 학생들이 실제로 구상하는 작품과 더 맞아떨어집니다.

- 로맨스판타지(로판) — 이세계·귀족 사회를 배경으로 한 로맨스 중심 판타지
- 학원·아카데미물 — 학교/아카데미를 무대로 한 성장·경쟁 서사
- 헌터·균열물(도시 판타지) — 현대 도시에 이물질/균열/각성자가 등장하는 설정
- 무협 — 전통 무협 세계관
- 아포칼립스·좀비물
- 오피스·사내 로맨스 — 회사를 배경으로 한 현실적 관계극
- 대체역사물 — 실제 역사를 다르게 바꾼 세계

이렇게 확장하면 **6개 → 12~13개**가 됩니다.

---

## 5. "플롯의 종류" — 크리스토퍼 부커의 7가지 기본 플롯 + 웹툰 트렌드 소재

**부커의 7가지 기본 플롯**은 서구 스토리텔링에서 가장 널리 인용되는 플롯 분류입니다.

1. **괴물 극복형** — 주인공을 위협하는 존재(적/괴물)를 물리치는 이야기
2. **입신출세형** — 가난한 주인공이 부와 힘을 얻었다가 잃고, 성장하며 다시 되찾는 이야기
3. **탐색형** — 중요한 목표물/장소를 향해 동료들과 떠나는 여정
4. **여행과 귀환형** — 낯선 세계로 갔다가, 그곳의 시련을 겪고 성장해 돌아오는 이야기
5. **희극** — 갈등이 점점 꼬이다가 하나의 사건으로 한 번에 풀리며 행복하게 끝남
6. **비극** — 치명적 결함이나 실수로 파멸에 이르는 주인공의 이야기
7. **재생형** — 어떤 사건을 계기로 주인공이 완전히 달라진 사람이 되는 이야기

기존 6개 중 "구출·모험 서사"는 탐색형/여행과 귀환형과, "복수극"·"추적·탐정물"은 괴물 극복형과 겹칩니다. 여기에 **입신출세형·희극·비극·재생형**을 추가하면 부커의 7유형을 모두 커버합니다.

여기에 최근 웹툰 시장의 강력한 트렌드인 **"회빙환"(회귀·빙의·환생)** 소재를 더할 수 있습니다.
- **회귀** — 기억을 유지한 채 과거의 자기 자신으로 돌아감
- **빙의** — 기억을 유지한 채 다른 인물(주로 창작물 속 조연/악역)의 몸에 들어감
- **환생** — 기억을 유지한 채 새로운 인물로 다시 태어남

이 세 소재는 "이미 아는 미래를 바꾼다"는 강력한 사이다 서사 엔진이라 웹툰 학생들에게 특히 실용적인 선택지입니다. 여기에 **계약관계물**(계약 연애/결혼), **능력자·먼치킨물**(압도적 능력으로 문제를 해결), **서바이벌·데스게임물**도 함께 후보로 넣을 만합니다.

→ "플롯의 종류"는 **6개 → 15개 안팎**까지 확장 가능. 단, 회빙환·계약관계·먼치킨물처럼 "장르 소재"에 가까운 항목과 부커의 "플롯 형태"는 성격이 다르므로, 구축 단계에서 하나의 목록으로 섞을지 `optgroup`으로 나눠 보여줄지 결정이 필요합니다 (아래 7번 참고).

## 6. "엔딩의 종류" — 소폭 보강

현재 6개(해피/새드/열린/배드/비터스윗/반전)가 이미 주요 결말 유형을 잘 커버합니다. 다만 다음을 추가하면 더 다양해집니다.

- **순환형 결말** — 이야기가 처음 장면·상황으로 돌아가며 끝남 (여운/재해석 유도)
- **희생형 결말** — 주인공(혹은 조력자)의 희생으로 갈등이 해소됨

→ 6개 → 8개.

---

## 7. 구축 시 고려할 UX 이슈

- 옵션이 6개→10~15개로 늘어나면 드롭다운이 길어집니다. 이미 있는 "직접 입력" 옵션은 그대로 유지하되, "플롯의 종류"·"세계관"처럼 항목이 많아지는 카테고리는 `<optgroup>`(예: "고전 플롯형" vs "웹툰 트렌드 소재")으로 묶어 스캔하기 쉽게 만드는 것을 제안합니다
- "성격" 카테고리는 이미 "캐릭터 설정" 탭에 MBTI·에니어그램이 따로 있으므로, 여기서는 지금처럼 짧고 직관적인 형용사형 태그를 유지하되 대칭 쌍(예: 순진한 ↔ 냉소적인, 헌신적인 ↔ 이기적인)을 추가하는 정도로 완만하게 확장하는 것을 제안합니다 (별도 프레임워크 리서치보다는 기존 방식의 자연스러운 연장)
