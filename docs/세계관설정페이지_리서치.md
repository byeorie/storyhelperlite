# 세계관 설정 페이지 구축 리서치

작성일: 2026-08-18 · 대상: StoryHelperLite "세계관 설정" 페이지 신규/확장 설계용 참고자료

---

## 1. 현재 상태 (app.js `rBg()` 함수)

지금은 "세계관"과 "배경"이 **하나의 카드로 통합**되어 있고, 필드는 다음 7개뿐입니다.

| 필드 | 내용 |
|---|---|
| 한 줄 요약 | 이 세계는 어떤 곳인가 |
| 시대 | 현대/중세/근미래 등 |
| 장소 | 도시/왕국/우주선 등 |
| 세계의 규칙 | 마법·기술·금기 등을 한 텍스트박스에 통합 |
| 사회·정치적 배경 | 자유 서술 |
| 전체 분위기/톤 | 자유 서술 |
| 세부 묘사 | 자유 서술 |

별도로 "작법 안내" 탭에 세계관 **유형** 선택 드롭다운(현실 세계 / 시대극·사극 / 이세계·판타지 / SF·미래 / 초자연·호러 / 디스토피아·대안현실)이 있고 각 유형별 조언 문구가 딸려 있지만, 이건 저장되는 설정이 아니라 안내용입니다.

즉 지금 구조는 "세계 규칙을 큰 텍스트 하나에 몰아넣는" 수준이라, 학생이 세계관을 체계적으로 쌓아가기엔 항목이 성글다는 것이 개선 지점입니다.

## 2. 해외 표준 세계관 구성요소 (Kindlepreneur 등 라이팅 가이드 종합)

소설/판타지 창작 교육에서 공통적으로 제시하는 10개 대분류입니다.

1. **지리·환경** — 대륙/지역/도시, 기후, 동식물, 천연자원, 지도
2. **역사·연표** — 시대 구분, 주요 사건사, 문명의 흥망
3. **사회·문화** — 종족/계층 구조, 도덕규범, 가족 구조, 달력·풍습
4. **정치·통치** — 정치체제, 법 제도, 대외관계, 이념
5. **경제** — 화폐, 교역로, 산업, 계급별 생활수준
6. **언어·명명** — 언어 체계, 인명·지명 작명 규칙
7. **일상·의식주** — 의복, 음식, 예술, 축제, 오락
8. **마법/기술 체계** — 규칙과 대가, 접근 가능 계층, 세계에 미치는 영향
9. **종교·신화** — 신·창조 신화, 세계관, 의식
10. **전쟁·갈등·세력** — 군사 구조, 무기, 세력 간 대립, 저항 세력

가이드는 "이 항목을 전부 채우기보다, 이야기에서 구멍이 드러나는 부분만 채우라"고 조언합니다 — 학생용 페이지 설계에도 그대로 적용할 만한 원칙입니다 (완주 부담을 줄이는 UX).

## 3. 웹툰 연재 특화 관점 — "설정 관리" 항목 (Slima 세계관 정리 시트)

위 2번이 "세계에 무엇이 있는가"라면, 이건 "연재 중 설정 실수를 어떻게 막을 것인가"에 대한 실무 항목입니다. 장편 연재를 하는 웹툰 특성상 학생들에게 특히 유용합니다.

| 항목 | 목적 |
|---|---|
| 검색어 | 나중에 이 설정을 찾을 때 실제로 검색창에 칠 단어 (용어 통일) |
| 한 줄 정의 | 설정을 즉시 확인할 수 있는 한 문장 요약 |
| 첫 등장 회차 | 몇 화에서 처음 나왔는지 — 독자가 이 설정을 얼마나 알고 있는지 판단하는 기준. 저자가 "유지 비용 대비 가장 유용한 항목"으로 꼽음 |
| 절대 규칙 | 이 설정이 절대 어겨서는 안 되는 선 |
| 독자 공개 범위 | 독자에게 이미 공개된 부분 vs 아직 비공개인 부분 |
| 떡밥 회수 여부 | 깔아둔 복선 중 아직 회수 안 한 것 표시 |
| 관련 항목 연결 | 다른 설정 카드와 링크 — 중복 서술 방지 |

## 4. 새 페이지 구성 제안 (그룹핑 초안)

교수·학생 대상이라는 점을 고려해 "입력 부담이 크지 않으면서도 위 표준 요소를 커버하는" 그룹 구성을 제안합니다. 기존 필드(한 줄 요약/시대/장소)는 그대로 살리고, 비어 있던 영역만 보강하는 방향입니다.

- **A. 기본 정보** — 한 줄 요약, 세계관 유형(기존 드롭다운을 저장 필드로 승격), 시대, 장소
- **B. 지리·역사** — 주요 지역/장소, 간단 연표(주요 사건 3~5개)
- **C. 사회 구조** — 정치체제, 계급/종족·세력 구도, 경제(선택 입력)
- **D. 규칙 체계** — 마법·기술·초자연 규칙과 대가, 금기 (기존 "세계의 규칙"을 세분화)
- **E. 문화·일상** — 풍습, 종교, 언어·호칭 특징 (선택 입력)
- **F. 갈등·세력** — 대립 세력, 전쟁/분쟁 요소
- **G. 설정 관리(용어사전)** — 위 3번 항목 기반: 용어명 / 한 줄 정의 / 첫 등장 회차 / 절대 규칙 / 독자 공개 범위 / 떡밥 회수 여부. 반복 추가 가능한 카드형 리스트로 구성하면 연재 진행하며 계속 쌓아갈 수 있음

B·C·E는 "선택 입력"으로 두어 학생이 필요한 항목만 채우게 하는 것이 완성도 압박을 줄이는 데 도움이 됩니다.
